# 白平衡偏移

- 中点：5250K
- 相机范围：2500-10000K
- V480 闪光灯的色温约为 5600K

## 一、白平衡偏移四个方向

- B (Blue)－蓝色：画面偏冷，带蓝调
- A (Amber)－琥珀色/暖色：画面偏暖，带黄橙调
- G (Green)－绿色：画面带绿色偏色
- M (Magenta)－洋红色：画面带洋红（红紫）偏色

## 二、相机色温范围

一般情况（包括尼康 Z5）：

- 最低：大约 2500K（很偏蓝，适合暖色光环境，比如烛光、钨丝灯）
- 最高：大约 10000K（很偏黄/红，适合蓝色环境，比如阴天、傍晚、海边）
- 步进：通常以 10K 或 50K 为单位调节

## 三、常见光源色温参考

| 光源 | 色温（K） | 白平衡感觉 |
|------|------|------|
| 蜡烛 | 1800-2000 | 很暖、偏红 |
| 钨丝灯 | 2800-3200 | 暖黄 |
| 荧光灯 | 4000-5000 | 偏冷或偏绿 |
| 日光（中午） | 5200-5500 | 中性 |
| 阴天 | 6000-6500 | 稍冷 |
| 阴影 | 7000-8000 | 更冷 |
| 蓝天/黄昏 | 9000-10000 | 很冷 |

## 四、AWB 工作流程

取景阶段 → 拍照瞬间 → 保存阶段

- 实时取景：AWB 实时分析画面，继续微调色温（不断采样 RGB，重点参考对焦点）
- 半按快门：最终计算并锁定
- 快门完全按下：应用到 JPEG 元数据
- 照片写入存储卡：只存结果（不再改），RAW 仅记数值

## 五、什么是白平衡偏移

白平衡偏移，是指在相机白平衡原有参数的基础上，额外进行偏色调整，以此来渲染画面氛围，达到我们想要的拍摄效果。

拍摄现场中的光线往往是很复杂的，当自动白平衡甚至是自定义白平衡都不能满足要求时，我们可以通过调节"白平衡偏移"参数，使得照片色调更符合实际情况。

## 六、白平衡偏移的作用

### 1. 控制颜色偏移程度

白平衡偏移能够很好的控制颜色的偏移程度。比如：拍出来的照片色调偏红了，那么你把白平衡偏移上的小白点往反方向移就能减弱红色调了。

### 2. 渲染画面氛围

白平衡偏移功能还可以对画面进行色彩的渲染。比如：在拍摄日出和日落时，天边的云霞不是很红，那么你可以把白平衡偏移中的红色移向红色，以此来渲染整个画面。

## 七、白平衡偏移调节

- G：代表偏向绿色
- A：代表偏向红色
- M：代表偏向紫色
- B：代表偏向蓝色

### 三色原理

- 红色 + 绿色 = 黄色
- 绿色 + 蓝色 = 青色
- 蓝色 + 红色 = 洋红
- 蓝色 + 洋红 = 紫色
- 洋红 + 红色 = 深红

## 八、白平衡偏移风格组合

### 1. A+G 胶片港风

王家卫风格港风，给人印象就是偏黄绿色，可以适当再提高色温，但注意不要过于偏向洋红。

### 2. B+G 日系小清新

小清新一般就是，整体色调偏冷，但是带一点蓝绿色调，所以可以往 BG 方向调整。

### 3. M+B 昭和情绪

整体色彩风格是偏浓郁的，蓝紫色就很适合拍摄昭和风格或者海边情绪风格。

### 4. M+A 复古情绪

整体照片偏浓，色彩上偏黄红，拍摄时可以适当提高一部分色温。

## 九、YCrCb 表示

蓝色、琥珀色、洋红、绿色，其实非常接近 Cr-cb 平面上的四个主要方向：

1. 蓝色 = Cb 大正向（向上）
2. 琥珀色 = Cb 大负向（向下，偏黄/橙/暖色，常叫 amber）
3. 洋红 = Cr 大正向 + Cb 正向（右上，magenta/品红）
4. 绿色 = Cr 大负向（向左，cyan-green 方向）
