# 调色顺序

> 基础校正 → 风格化 → 局部精修

## 一、基础校正（先调曝光 → 再调对比 → 最后调颜色）

1. 先把画面整体亮度调合理（Brilliance + Exposure + Highlights/Shadows）
2. 再把动态范围拉开一点（提暗部、压亮部）
3. 然后微调对比度，让画面更有立体感
4. 最后才动颜色（白平衡 → 饱和度/鲜艳度）

## 二、注意事项

### 1. 亮度参数

- 增加曝光是把照片里的所有像素都改变
- 增加亮度是优先提亮暗部保护高光

### 2. 饱和度参数

- 提高饱和度是提高所有像素的饱和度
- 提高自然饱和度是优先提高低饱和度像素的饱和度
