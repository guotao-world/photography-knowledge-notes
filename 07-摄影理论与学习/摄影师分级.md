# 摄影师分级

顶级摄影师本质上是在"导演现实"，而不是在"操作相机"。

相机只是工具，真正的创作单位是：人 + 光 + 空间 + 时间 + 情绪。

## 一、分级

### 1. 初级摄影师

"我拍她"——以"记录对象"为核心，完成对人物的直接拍摄。

### 2. 中级摄影师

"我让她摆姿势"——以"姿态控制"为核心，通过引导模特完成预设的造型与动作。

### 3. 高级摄影师

"我让她进入状态"——以"状态引导"为核心，通过沟通与节奏控制，使被摄对象进入自然或情绪化表达状态。

### 4. 顶级摄影师

"我让某个瞬间发生"——以"瞬间生成"为核心，通过对情绪、节奏与环境的整体调度，使具有表现力的关键瞬间自然发生并被捕捉。
