# 景深计算

> 核心是弥散圆

## 一、景深公式

景深 ΔL = 焦点平面弥散圆直径。

相关概念：

- 近点、远点
- 后景深 / 前景深
- 近点距离 / 远点距离
- 前焦深 / 后焦深
- 物距 L / 像距

式中：

- δ：容许弥散圆直径
- f：镜头焦距
- F：镜头使用的光圈值
- L：物距

前景深：ΔL1 = FδL / (f + FδL)

后景深：ΔL2 = FδL / (f - FδL)

景深 = ΔL1 + ΔL2 = 2fFδL / (f² - F²δ²L²)

## 二、物距、像距、焦距关系

物距：u、像距：v、焦距：f

1/u + 1/v = 1/f

如下图：物体点到透镜、透镜到聚焦点形成两个共轭（共用底边）的等边三角形。

在物体、像点两者位置关系不变（u+v 不变）时且容许弥散圆大小不变，当焦距变大，等于把透镜往左移，右边三角形拉长，顶点角（透镜对于像点的张角）变小，于是焦深加大；左边三角形缩短，顶点（透镜对于物点的张角）加大。就是景深与焦深呈反向变化。

简单说：实际上，景深跟物距相关，物距越小、景深越小；物距越大，景深越大。而焦距加大造成实物距变小。

> 顺便可以得知：为什么微距摄影时，景深特别浅，很容易虚焦。

## 三、景深原理示意图

- 大光圈：光线通过大孔径透镜，焦点位置前后的物体快速虚化，景深较浅
- 小光圈：光线通过小孔径透镜，焦点位置前后的物体保持清晰的范围更大，景深较深
