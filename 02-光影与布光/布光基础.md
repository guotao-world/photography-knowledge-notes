# 布光基础

## 一、人像布光学习路径

1. **机顶闪（On-Camera Flash）**：TTL 自动闪光、M 手动闪光、跳闪 vs 直打
2. **离机闪（Off-Camera Flash）单灯**：45° 主光（伦勃朗光、蝴蝶光、侧光）、光质（硬光 vs 软光）、光比（闪光 vs 环境光）
3. **两灯布光**：主光 + 辅光（控制阴影）、主光 + 轮廓光（勾边）
4. **三点式布光（经典人像）**：主光（面部塑形）、辅光（柔化阴影）、轮廓光（背景分离）
5. **扩展布光**：背景光（增强氛围）、发光（头发层次）、特殊效果光（彩色滤片、图案片）

> 练习建议：每一步至少拍上几十张，熟悉光的变化；单灯能控制好，再加第二灯，否则光会乱；先学"光的方向和质感"，再学"光比和层次"。

## 二、光的方向与质感（第一步）

这是最基础的，因为光照方向决定了人物脸部的明暗结构和情绪氛围。

### 方向

- 正面光：脸部均匀，几乎没有阴影 → 清晰但容易"平"，多用于证件照
- 45° 侧光：脸部一明一暗 → 立体感强，是人像摄影最常用的布光
- 侧光（90°）：半边脸亮，半边脸暗 → 神秘感强
- 逆光：主体边缘有亮边 → 分离人物和背景，营造梦幻感
- 俯光（从上往下）：符合自然光方向（太阳、灯泡），更自然
- 仰光（从下往上）：制造恐怖感（鬼片常用）

### 质感（光质）

- 硬光（小光源/直打闪光灯）：阴影边缘锐利，清晰度高，但显缺陷
- 软光（柔光箱、反光伞、大窗户光）：阴影柔和，肤质更好看

> 为什么先学这个？因为只要学会控制光的方向和硬/软，就能塑造一个脸部的"立体感"。哪怕只用一个光源，你也能拍出很好的人像。

## 三、光比与层次（第二步）

光比就是主光和辅光、主光和环境光的亮度比例，它决定了画面的对比度和情绪。

- 小光比（高调光）：主光和辅光亮度差很小 → 阴影淡、画面亮 → 清新柔和。例：广告人像、美妆照
- 大光比（低调光）：主光明显比辅光亮 → 阴影深、对比强 → 戏剧性、神秘感。例：电影风格、男人人像
- 主光比环境光亮：主体突出，背景暗
- 主光接近环境光：氛围均衡，柔和自然

> 为什么放在第二步？因为如果你连光的方向都控制不好，光比再怎么调整也会乱。只有先会塑形（方向、质感），再用光比去"控制气氛"，照片才会高级。

## 四、练习例子

1. 用一个闪光灯 + 柔光伞：先摆 45° 方向，看看脸的立体感；然后换成正面光、侧光、逆光，比较阴影差异
2. 确定方向后，加一个反光板：调整距离，看阴影的深浅变化 → 体会光比对氛围的影响

> 第一阶段：学会"光从哪里来""光是硬还是软"，解决脸型立体感和肤质好不好看。
> 第二阶段：学会"光有多强"，解决画面情绪和氛围。

## 五、三点式布光

三点式布光（Three-Point Lighting）是最经典的人像布光方式，摄影棚、电影、广告人像都会用到。

### 1. 主光（Key Light）

主体的主要光源，决定画面基调。

- 位置：通常放在相机左前方或右前方 30°～45°，略高于眼睛
- 亮度：最强的光源

### 2. 补光（Fill Light）

用来减弱主光产生的阴影。

- 位置：相机另一侧，角度更低，可以用反光板或柔光灯
- 亮度：一般比主光弱 0.5~2 档

### 3. 轮廓光/背光（Back Light/Rim Light）

从背后或侧后方打到人物边缘，勾勒轮廓，把人物从背景分离出来。可以制造立体感，避免"人物贴在背景上"。

- 亮度：可强可弱，根据风格调整

## 六、常见布光方式

| 布光方式 | 说明 | 适用场景 |
|------|------|------|
| 单点光（One-Light Setup） | 只用一个光源（通常是主光），简单直接，氛围感强 | 只用窗户光拍人像 |
| 双点光（Two-Light Setup） | 主光 + 辅助光（补光/背光），比单光更有层次感 | 比三点式更简单的场景 |
| 三点式布光（Three-Point Lighting） | 主光 + 补光 + 轮廓光，最经典、最均衡 | 几乎万能 |
| 蝴蝶光（Butterfly Lighting） | 主光位于镜头正上方，鼻子下出现"蝴蝶状"阴影 | 女性人像、时尚杂志，修饰脸型 |
| 伦勃朗光（Rembrandt Lighting） | 主光 45° 左右打向人物，另一侧脸颊形成小三角亮斑 | 经典、富有油画感 |
| 分割光（Split Lighting） | 主光打在一侧，另一侧完全黑暗 | 强烈对比、戏剧效果 |
| 环形光（Loop Lighting） | 主光在 30°～40°，鼻子下产生小"环状"阴影 | 介于蝴蝶光和伦勃朗光之间，比较自然 |
| 高调光（High-Key Lighting） | 整体画面明亮、阴影很少 | 时尚、广告、婚纱 |
| 低调光（Low-Key Lighting） | 画面整体较暗，光比大，阴影多 | 神秘、戏剧、张力的氛围 |

## 七、总结

- 唯美人像：环形光、蝴蝶光、高调光
- 有质感的人像：伦勃朗光、低调光
- 戏剧效果：分割光、低调光
- 万能：三点式布光

## 八、轮廓光与主光的关系

如果轮廓光 > 主光，画面就会发生一些明显的变化：

1. 人物变得"发光"：头发、肩膀、侧边会特别亮，像被镶了一圈光边；如果布光角度狠一点，甚至像人物被灯光从背后切割出来
2. 脸部会显得偏暗：主光太弱，面部细节不够突出，观众的注意力会被边缘亮点吸引，而不是人物的脸；容易出现"脸陷下去，边缘突出"的违和感
3. 视觉重心转移：人像中，正常情况是脸最亮 → 观众视线首先看脸；如果轮廓光大于主光，观众的注意力会跑到边缘线，脸反而不重要了
4. 氛围感强烈：可能呈现舞台灯光、时尚大片、MV、广告风格；有点戏剧化，甚至带剪影感

| 风格 | 光的关系 | 效果 |
|------|------|------|
| 常规人像 | 主光 > 辅光 > 轮廓光 | 脸最亮 |
| 营造氛围 | 主光 ≈ 轮廓光 | 平衡 |
| 艺术/舞台感 | 轮廓光 > 主光 | 边缘发光，脸部弱化 |
