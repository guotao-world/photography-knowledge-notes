# 脸型与光位

| 脸型 | 问题特点 | 推荐光位/拍摄角度 |
|------|------|------|
| 圆脸 | 显胖、缺少线条感 | 45° 侧光、伦勃朗光；微俯拍 |
| 方脸 | 下颌线硬，显刚 | 蝴蝶光、柔光；三分之二侧脸 |
| 长脸 | 过修长，比例失衡 | 平光环形光；略俯拍 |
| 瓜子/鹅蛋 | 五官均衡，百搭 | 任意光位；正面或侧面都可 |
| 心形脸 | 额头宽，下巴尖 | 环形光、柔光；微俯拍减尖锐 |
| 大饼脸 | 脸宽、额头宽 | 45° 侧光；三分之一侧脸；略仰拍 |
| 高颧骨 | 颧骨突出，显刻薄 | 环形光、蝴蝶光；微仰拍 |

## 一、记忆小口诀

- 圆→侧光收窄
- 方→柔光削角
- 长→平光压缩
- 瓜子→百搭全能
- 心形→柔和减尖
- 大饼→侧脸修饰
- 高颧骨→环光柔化
