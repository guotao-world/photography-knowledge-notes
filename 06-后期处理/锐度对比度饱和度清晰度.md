# 锐度、对比度、饱和度、清晰度

## 一、优化校准

### 1. 锐度

亮度有变化的位置做处理，亮度不变的位置不改变。只作用于物体的边缘，但原理有所不同。

锐化主要是通过在边缘两侧，增加黑白相间的高对比线条"隔离带"，让边缘看起来更加突出锐利。

### 2. 对比度

增大对比度就是提亮亮部，降低暗部。

### 3. 饱和度

全图像的饱和度。

### 4. 自然饱和度

对饱和度低的区域影响比较大，对饱和度高的区域影响比较小。

### 5. 清晰度

清晰度是一种特殊的锐化，把隔离带弄得过度平滑一些。

当我们增加照片的清晰度，靠近边缘较暗的一侧会变得更暗，靠近边缘较亮的一侧会变得更亮，但这种亮度对比的变化只局限在边缘周围的部分。

## 二、尼康优化校准

### 优化校准设定

| 选项 | 说明 |
|------|------|
| 效果级别 | 减弱或增强 Creative Picture Control（创意优化校准）的效果 |
| 快速锐化 | 快速均衡调整锐化、中等锐化和清晰度的级别。这些参数也可逐个调整 |
| 锐化 | 控制细节和轮廓的锐利度 |
| 中等锐化 | 在锐化和清晰度之间的范围内调整图案和线条的锐利度 |
| 清晰度 | 在不影响亮度或动态范围的情况下调整总体锐利度和较粗轮廓的锐利度 |
| 对比度 | 调整对比度 |
| 亮度 | 在不损失亮部或暗部细节的同时提高或降低亮度 |
| 饱和度 | 控制色彩的鲜艳度 |
| 色相 | 调整色相 |
| 滤镜效果 | 模拟彩色滤镜在单色照片中的效果 |
| 调色 | 选择单色照片中使用的色调。选择了 B&W（黑白）以外的选项时，按下可显示饱和度选项 |
| 调色（创意优化校准） | 选择用于 Creative Picture Control（创意优化校准）的颜色的浓淡 |
